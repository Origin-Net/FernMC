# FernMC

FernMC is a Minecraft: Bedrock Edition server software written in Go. Forked from Dragonfly.

## Getting Started

Running FernMC requires at least **Go 1.26**.

```shell
git clone https://github.com/Origin-Net/FernMC
cd FernMC
go run main.go
```
